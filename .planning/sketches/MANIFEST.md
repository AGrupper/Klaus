# Sketch Manifest

## Design Direction
The Klaus Hub's Native skin: iOS grouped-list surfaces on a `#F2F2F6` ground, midnight
accent, dark-red flame, SF Pro display/text, 12px radii. Sketches reuse the live tokens
from `frontend/src/index.css` verbatim so a decision here transfers to the app unchanged.
Quiet, papery, phone-first — the Hub is read at a glance on an iPhone, not studied.

## Reference Points
The Hub itself (`frontend/src/components/home/HomePage.tsx`) — sketches render the real
Today page shell (greeting, Talk to Klaus, timeline rows, morning numbers) so the note is
judged in context, never in isolation.
