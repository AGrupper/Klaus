<objective>
Route the Sunday weekly training review through the cascade — with the one asymmetry that
defines it: it never self-skips.

D-03 is precise about what changes. The weekly's triage judgment governs **shape and
emphasis** — what this week is about, which topics lead, whether it is a scorecard week or
a "you've been sick, here's the reset" week — and never whether it fires. A missing Sunday
leaves a hole in the training record; a fixed cadence with judged content is the real win
over the template. The only thing that can still silence it is the Phase 31 Step-0
standing-directive veto, which this plan must preserve exactly.

Plan 33-04 implements this as `advisory_only=True`: Layer 1 still runs and its
draft/reason still shape the compose, but a `should_act=False` verdict does not stop the
send.

Purpose: OCC-03 — the last legacy composer moves onto the shared cascade.
Output: a cascade-routed `run_weekly_review` behind `OCCASION_CASCADE`, a `weekly_reviews`
state doc so the heartbeat can tell "not fired" from "vetoed", and the surviving
deterministic topic-derivation machinery left alone.
</objective>
