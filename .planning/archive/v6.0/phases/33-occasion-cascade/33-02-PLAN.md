<objective>
Give Layer 2 the D-21/D-22 behaviour it needs to be genuinely agentic without ever
producing a truncated or apologetic occasion message.

Today `_run_smart_loop` exits the `for iteration in range(MAX_TOOL_ITERATIONS)` loop and
falls straight to "return `last_response_text` if >100 chars, else an apology". D-22
requires an intermediate step: strip the tools, take exactly one more turn, and force a
real final answer out of everything gathered in the 12 prior iterations. Only if that
forced turn also fails does the existing fallback chain apply.

This is a shared file — every chat turn and the `*/20` tick get the same improvement,
which is exactly D-36's "one place to change behavior" philosophy. No occasion-specific
cap is added anywhere (D-21).

Purpose: without this, a thorough occasion compose that used its full tool budget
silently degrades to the free triage draft (or an apology), which D-22 forbids.
Output: a forced-final turn in `_run_smart_loop`, a `max_tokens` passthrough for the
weekly review's oversized compose, and the stale `MAX_TOOL_ITERATIONS = 8` fixed in
`core/self_manifest.py`.
</objective>
