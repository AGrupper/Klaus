<objective>
Build the two new Firestore stores this phase needs, plus the shared test-helper
module every later occasion test file imports.

`ActionLogStore` is the D-25 action-audit trail: a per-day record of every write
Layer 2 made to Amit's calendar/tasks, written **at action time** and explicitly
**not** gated on send success — the deliberate inverse of the `OutreachLogStore`
D-10 write-after-send invariant. `OccasionInFlightStore` is the D-19 lightweight
marker that lets the `*/20` tick yield when an occasion is mid-compose.

Purpose: every downstream plan (cascade core, calendar writes, `get_recent_decisions`,
heartbeat anomalies) reads or writes one of these two stores. They are the contracts;
implementations come later.
Output: two new store classes in `memory/firestore_db.py`, a new
`tests/occasion_helpers.py` scaffolding module, and store unit tests.
</objective>

  <action>
    Add `class ActionLogStore` to `memory/firestore_db.py`, placed immediately after
    `OutreachLogStore` so the two write disciplines sit side by side and the contrast is
    visible in the source.

    Collection: `action_log`; one document per `YYYY-MM-DD`; fields `date: str`,
    `entries: list[dict]`, `updated_at: firestore.SERVER_TIMESTAMP` (doc level only).

    `append(date_str, entry)` — identical mechanics to `OutreachLogStore.append`:
    `self._col.document(date_str).set({"date": date_str, "entries": firestore.ArrayUnion([entry]),
    "updated_at": firestore.SERVER_TIMESTAMP}, merge=True)`, log-and-re-raise on failure.
    The class docstring MUST state, in its own words, that this store is deliberately
    **not** gated on `send_and_inject` success (D-25) — the exact inverse of
    `OutreachLogStore`'s D-10 rule — and that the two logs must never be merged.
    Re-state NOTE 2: no `SERVER_TIMESTAMP` sentinel inside `entry` (ArrayUnion deep-equality),
    use the static ISO string in `entry["at"]`.

    `get_recent(days, *, today=None)` — iterate the last `days` date keys backwards from
    `today` (default: `datetime.now(ZoneInfo("Asia/Jerusalem")).date()`), read each doc,
    and return a flat list of entries, each carrying its `date` key. Never raises —
    returns `[]` on any Firestore error, matching `OutreachLogStore.get_today`'s read
    contract. Every returned entry MUST pass through `_jsonsafe_doc` before it is
    returned, because `get_recent_decisions` (plan 33-09) `json.dumps` the result and
    `updated_at` round-trips as `DatetimeWithNanoseconds`.

    `undisclosed(days=7, *, today=None)` — `get_recent(days, today=today)` filtered to
    `entry.get("disclosed") is not True`. Feeds the Layer-2 disclosure block (plan 33-04)
    and heartbeat anomaly #4 (plan 33-11).

    `mark_disclosed(date_str, action_ids)` — read the day's `entries` list, set
    `disclosed=True` on every entry whose `id` is in `action_ids`, write the whole
    `entries` list back with `set({"entries": [...]}, merge=True)`. ArrayUnion cannot
    update an element in place, so this is a read-modify-write; document the
    last-writer-wins caveat in the docstring (single-writer in practice — one occasion
    at a time, enforced by the D-19 in-flight marker). Never raises.
  </action>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-33-06 | Repudiation | `ActionLogStore.append` | mitigate | Append is unconditional and re-raises on failure, so a write action can never be silently unlogged; the write-at-action-time contract (D-25) is documented in the class docstring and asserted by a test |
| T-33-07 | Denial of Service | `OccasionInFlightStore.active` | mitigate | Fail-open: missing doc, unparseable/expired `expires_at`, or any exception all return `None`, so a poisoned or orphaned marker cannot mute the `*/20` tick beyond `ttl_seconds` (900s) |
| T-33-03a | Information Disclosure | `ActionLogStore.get_recent` | mitigate | Reads route through `_jsonsafe_doc`; no raw Firestore sentinel objects escape into `json.dumps` (the MealStore/TrainingLogStore crash class).
